## Numpy


### 1. 명시적 타입 배열 생성과 다차원 슬라이싱 


- 방의 크기
    - 비트(bit) - 0,1
    - 바이트(byte) - 비트 x 8 (-256 ~ 255)
#### 배열
- 메모리상 연속된 구조, 인덱스 연산자([]) 접근 가능
- 동일한 자료형으로 데이터가 구성
- C언어로 개발(직접 메모리에 접근)
- dtype: 자료형 명시 (예- np.int64, np.float64)
#### 배열 종류
- 1차원 배열(vector)
- 2차원 배열 (Matrix)
- 3차원 배열 (Tensor)

#### 배열 선텍, 슬라이싱
- matrix[행, 열] 
- matrix[0:2, 1:3] : 행은 0, 1, 열은 1, 2
- matrix[:, 0] -> 모든 행의 0번째 열
- matrix[1:, :2] -> 행은 1번 인덱스 부터 전체, 열은 1번 인덱스 이하


### 차원변경 (reshape, flatten)과 축(Axis)

#### reshape(행, 열)/ flatten()
- reshape(행, 열) - 1차원 배열 -> 지정된 행과 열 구조로 차원수를 변경, -1: 자동 결정
- arange(시작, 종료, 증감단위) -> 시작 이상 종료 미만으로 숫자를 생성
- faltten() - 2차원 배열 -> 1차원으로 평탄화

#### 축(axis)
2차원 배열에서 연산의 방향을 설정
- axis: 0 -> 행기준에서 연산
- axis: 1 -> 열기준에서 연산

#### 행렬 전치(Transpose) 및 행렬곱(@)
- 객체.transpose() -> {행, 열} -> {열, 행} / 전치
    - 객체.T
- 행렬 곱 연산(@)

### DataFrame
- 2차원(행, 열) 구조체

#### 데이터 탐색 속성(Shape, dtypes)과 진단(info, describe)
- 탐색적 데이터 분석(EDA)
- df.info()
    - 누락치 확인(Non-Null count)
    - dtype: 통계가 가능한 자료형인지 체크(잘못된 데이터가 있는지 여부 확인 -> 치환 -> 자료형 변환)
- df.describe()
    - 평균, 중앙값, 최대, 최솟값을 통해서 이상치(극단치)를 확인

#### 데이터 변경 및 인덱스 제어 
- df.set_index : 인덱스를 변경
- df.reset_index : 다시 숫자형 인덱스로 변경
#### Pandas Series & DateFrame 브로캐스팅
- axis : 0 -> 행의 인덱스 기준
- axis : 1 -> 컬럼 기준

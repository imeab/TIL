## 기본 자료형과 형변환

### 주석
- `#` : 한 줄 주석
- `""" """` : 여러 줄 주석
- 주석은 코드 설명을 적을 때 사용하며 실행되지 않는다.

### 기본 자료형
- **정수(int)** : `10`, `20`
- **실수(float)** : `3.14`, `10.5`
- **문자열(str)** : `"안녕"`, `'Hello'`
- **논리형(bool)** : `True`, `False`
- **None** : 값이 없음을 의미

### 명시적 형변환
자료형을 직접 변환하는 방법

- `int()` : 정수
- `float()` : 실수
- `str()` : 문자열
- `bool()` : 논리형

### 묵시적 형변환
파이썬이 자동으로 자료형을 변환해준다.

예)
```python
10 + 3.5
```

→ `13.5` (정수가 실수로 자동 변환)

### ValueError
숫자로 바꿀 수 없는 문자를 `int()`나 `float()`로 변환하면 발생한다.

예)
```python
int("abc")
```

# 연산자

## 대입 연산자
- `=` : 값을 변수에 저장

예)
```python
age = 20
```

---

## 산술 연산자

- `+` : 더하기
- `-` : 빼기
- `*` : 곱하기
- `/` : 나누기
- `//` : 몫
- `%` : 나머지
- `**` : 제곱

### 연산 우선순위
1. `()`
2. `**`
3. `*`, `/`, `//`, `%`
4. `+`, `-`
5. `=`

---

## 비교 연산자

- `>` : 크다
- `<` : 작다
- `>=` : 크거나 같다
- `<=` : 작거나 같다
- `==` : 같다(동등성, 동일한 가치)
- `!=` : 다르다

비교 연산의 결과는 항상 `True` 또는 `False`가 나온다.

동등성 vs 동일성
- 동등성 : 동일한 가치를 비교(==)
- 동일성 : 동일한 대상인지 비교

예)
```python
10 > 5
# True

10 == 20
# False
```

조건문(if)이나 반복문(while)에서 많이 사용된다.

### 논리 연산자

and

- 각 항이 모두 True → True, 하나라도 False → False

or 

- 각 항의 하나라도 True → True,  모두 False → False

not

- True 조건 → False 조건으로 반전 , False 조건 → 조건으로 반전

비교 연산자 보다 우선순위가 낮다

### 복합 대입 연산자
대입 연산자(=) + 다른 연산자(주로 산술연산자와 결합)

예)
```python
num = 1
num += 1  # 단항 연산, num = num + 1
num += 1
num += 1

num
-> 4
```

### 부호 반전 연산자(-)

- 음수 -> 양수
- 양수 -> 음수

예)
```python  
num = 100

num2 = -num
num2
->-100
```

### 연산자 우선 순위

대입 연산자 (=)   < 논리연산자   < 비교 연산자    <  산술 연산자 < (…)

### 단락 회로 평가
왼쪽 항의 결과만으로 참/거짓 결과가 이미 확정되었으면 오른쪽 항은 실행 하지 않는 파이썬의 최적화 방식
- 첫 항의 결과가 True 이면 결과가 이미 결정되어 다음 연산 필요 x
- 첫 항의 결과가 Faslse 이면 결과가 결정이 안되어 다음 연산 필요(체크)

예)
```python
  result = True or 10**2
  result
  -> True
```

예)
 ```python
result = True or 10**2
result
-> 100
```

### 문자열 형식화

#### %연산자 방식

1. %s 문자열 대체
- %숫자s -> 최소 숫자 자리수 만큼 공간 차지, 남는 공간 공백
-  %대체문자숫자s -> %05s
2. %d 정수
- %대체문자숫자d → %05d → 남는 공백은 0 으로 대체
3. %f : 실수
- %2f : 소수점 2자리까지 표시
- %10.2f : 정수부 10 자리 소수점 2자리까지 표시

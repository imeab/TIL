## 조건문
- 판별식에 따라서 참(True)면 참에 실행되는 코드를 정의하고, 거짓(False)이면 거짓 조건에 실행되는 코드를 정의할 수 있는 문장
- 판별식 : 비교 연산자, 논리 연산자, 값

### 1. 단일 조건문: if
```python
if 판별식:
    판별식이 참일때 실행되는 코드
```

### 2. if-else 조건문
- 조건이 틀렸을때 (False)일떄 실행할 별도의 대응 명령이 필요할때
```python
num = 5
if num == 10:
    print("10 입니다")
esle: # if num == 10: 거짓일때 실행되는 코드를 정의
    print("10이 아닙니다")
```
### 3. 다중 조건 분기: if-elif-else
- elif는 else if의 파이썬 축약형으로, 상단의 조건들이 모두 False로 판명되었을 때 하위에서 새로운 대조 조건을 제시하는 역할

### 4. 복잡한 조건 처리: 중첩 조건문과 논리 연산자 결합
- 코드가 단순하거나 할따 논리 연산자 조건과 결합

## 반복문

### 1. for 문

횟수가 정해져 있는 반복
```python
for i in range(반복 횟수):
    # 반복 수행되는 코드
```
- i: 순서를 의미하는 index, 관례, 다음 for문은 알파벳 순서대로 j,k,l, ..
- 반복 횟수를 사용하지 않는 경우 _(언더 바)
- range(반복 횟수), 0~반복횟수
- range(시작, 종료): 시작 이상, 종료 미만, range(2, 5) -> 2, 3, 4
- range(시작, 종료, 증감단위)
  
반복 가능한 요소(iterable)의 반복
```python
for 요소 in 반복 가능 요소들
    # 반복 수행되는 코드
```

### 2. while 문
참인 조건에서 반복을 수행
```
while 조건식:
    #조건식이 참일떄 반복 수행되는 코드 
```
### 3. 반복문의 중간 제어: break와 countine
- continue: 현재 반복을 중단하고 새로운 반복을 시작(건너뛰기)
- break : 반복 중단

### 4. 이중 반복문과 시퀀스 중첩 순회
구구단
- 첫번째 반복은 단(2~8), 8회 반복
- 각 단마다 1~9를 곱하는 반복
```python
for i in range(2, 10): # 단
    print("-" *5, i, "단", "-"*5)
    for j in range(1, 10): # 곱하는 수
        print(f"{i} X {j} = {i*j}")
```

## 이터레이터와 제너레이터

### 1. 이터러블(Iterable)
- 반복 가능한 객체!
- __inter\__(..) 정의되어 있다면 반복 가능!

- __ next__ (..) 인덱스를 한칸씩 이동하면서 요소를 꺼내오는 기능을 정의
- 이터레이터(반복)

### 2. 이터레이터(Iterator)
**ex) 햄버거를 하나씩 건네주는 사람**

반복을 하려면 
- 이터레이터 객체 생성(__iter\__ 호출 iter()...))
- 순서를 한칸씩 이동하면서 요소 조회(__next\__ 호출(next(...)))
```python
fruits = ['Apple', 'Orange', 'Melon', 'Banana']

it = iter(fruits) # __iter__(..) 호출
```

### 3. 제너레이터(Generator)
**ex) 햄버거를 필요할때 직접 만들어서 주는 사람**
- 함수의 실행을 정지하고 원할 때 다시 재개하는 형태 

### 동기와 비동기
- 동기: 순서대로 실행하고  결과도 순서대로 도출 (순차적 실행) **ex) 전담마크**

- 비동기: 순서대로 작업을 시작하지만 결과는 먼저 처리된 순서로 나온는 방식 **ex) 식당 웨이터**

### 4. 제너레이터 표현석
- 참고: 리스트 컴프리헨션 -> 처음부터 메모리에 적재

- 리스트 대신 튜플로 리스트 컴프리헨션과 동일하게 사용하면 된다. -> 메모리 
소비가 적음
- 대용량 데이터 처리

## 모듈과 패키지!

### 1. 독립 소스 파일 모듈( )
- 모듈: 파이썬 파일 하나
- 다른 파일에서 모듈을 불러와서 사용하는 경우 많다.
- 모듈명은 파일 이름
- __name\__ : 모듈 이름ㅁ

### 2. 디렉터리형 패키지
- 패키지는 모듈을 모아 놓은 디렉토리
- from 패키지명. 하위패키지 import ...
- 전체 패키지 경로 : 절대 경로 접근 예) chapter06.mod1
- 상대 경로 접근법(..) : 바로 위 패키지
-   (.) : 현재 모듈이 있는 패키지

### 3. import, from, as 키워드
- import : 모듈 불러오기
- 불러온 모듈에서 마침표(.)를 통해서 접근
- from 모듈명/패키지명 import 모듈에 이쓴 함수, 변수, 클래스 등등
- from 모듈 import * -> 모듈의 전체 함수, 변수, 클래스를 불러온다.
- as : alias - 별칭 

#### _\_init\_\_
- 현제 디렉토리가 패키지임을 알려주는 파일
- 하위 모듈, 하위 패키지에서 공통적으로 처리해야 하는 코드를 작성, 모듈을 불러올때 최초 한번만 실행
- 패키지 내에서 사용할 공통적인 함수, 변수, 클래스를 정의
- from 패키지 import * : \_\_all\_\_ = [...] : 에 정의된 모듈만 임포트

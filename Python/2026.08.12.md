### 매개변수와 인수
- 매개변수 : 함수 호출시 압력 부분에서 값을 담아주는 변수
- 인수: 호출시 사용된 값

#### 메모리
1. 정적 메모리

- 한번 기록되면 제거x

2. 동적 메모리

- 실행중 생성과 소멸을 반복
- 힙 영역 메모리
  - pyFunctionObject
    - pycodeobject(함수의 매개변수 정의, 수행 코드 정의)

전역 변수: 함수 외부에 정의된 변수

지역 변수: 함수 내부에 정의된 변수

#### 컴파일 기반
- 실행하

#### 인터프리터 기반
- 소스 코드 -> 헌줄한줄 해석(실행중) -> 결과

### 위치 인수와 키워드 인수
- 위치 인수: 매개변수의 순서대로 값을 지정
- 키워드 인수 : 매개변수 명과 함께 값을 지정, 순서는 중요하지 않음

### 기본값 매개변수
- 매개변수에 값을 할당하지 않아도 기본적으로 가질 수 있는 값
- 기본값이 있는 매개변수는 오른쪽 끝부터 차례대로 정의

### 가변인수와 키워드 가변 인수
- *args: 가변적인 위치 인수, 매개변수 갯수 상관없이 지정 가능, 키워드 매개변수로는 사용 불가

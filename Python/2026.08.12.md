### 매개변수와 인수
- 매개변수 : 함수 호출시 압력 부분에서 값을 담아주는 변수
- 인수: 호출시 사용된 값

#### 메모리
1. 정적 메모리

- 한번 기록되면 제거x

2. 동적 메모리

- 실행중 생성과 소멸을 반복
- 힙 영역 메모리
  - pyFunctionObject
    - pycodeobject(함수의 매개변수 정의, 수행 코드 정의)

전역 변수: 함수 외부에 정의된 변수

지역 변수: 함수 내부에 정의된 변수

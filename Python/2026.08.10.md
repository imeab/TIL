## 자료구조 

> 날짜: 2026.08.10
---
순서가 있는 데이터를 모아놓은 자료구조이다.

* 인덱스는 `0`부터 시작한다.
* `[]`를 사용해서 원하는 위치의 값을 가져올 수 있다.
* 리스트는 값을 수정할 수 있다.

### 문자열(Str)
- 문자 여러개가 열지어 있는 형태, 순서가 있는 시퀀스
- 인덱스 연산자 [ ]로 접근 가능
- 슬라이싱 가능

### 리스트 (List)

```python
fruits = ["사과", "오렌지", "바나나"]
```

### 주요 메서드

**추가 (Create)**

* `append(값)` : 맨 뒤에 하나 추가
* `insert(위치, 값)` : 원하는 위치에 추가
* `extend(리스트)` : 원본 리스트 끝에 여러 값을 한 번에 추가
- `[기존 리스트] + [값1, 값2, ...]` : 끝에 여러개 추가

**조회 (Read)**

* `fruits[1]` : 인덱스로 값 확인
* `index(값)` : 해당 값의 위치 확인

**수정 (Update)**

인덱스를 이용해서 값을 변경할 수 있다.

```python
fruits[1] = "오렌지"
```

**삭제 (Delete)**

* `remove(값)` : 해당 값을 삭제
* `clear()` : 리스트의 모든 값 삭제

**기타**
- sort(): 정렬(오름차순, sort(reverse=True) : 내림차순
- reverse() : 순서 반전
- count(요소) : 특정 요소의 등장 횟수

### 튜플(Tuple)
- 변경 불가 리스트
- (값1, 값2, ....)
- (값1 ,) : 값이 하니인 튜플은 반드시 ,를 함께 추가
- 소괄호( ) 를 생략하고 , 콤마(,)로 값을 나열해서 정의
- 인덱스 연선 [] : 요소 접근
- count(요소) : 요소의 등장 횟수
- index(요소) : 요소의 위치 번호

### 인덱싱(Indexing)
- 인덱스 번호가 음수이면 (-1, -2..) : 오른쪽 부터 조회

### 슬라이싱(Slicing) 
- 리스트, 튜플에서 특정 구간을 가져올때(결과는 새로운 리스트, 튜플로 생성)
- [ 시작:] -> 시작점 인덱스부터 끝까지
- [: 종료] -> 종료 인덱스는 포함이 안된다. [:3] -> 0, 1, 2
- [시작: 종료] -> 시작 인덱스 이상, 종료 인덱스 미만, [2, 5] -> 2, 3, 4
- [시작:종료:증감단위] -> 시작지점에서 종료 지점 미만까지 증감 단위로 추출 [2:6:2] -> 2, 4

### 시퀀스 자료구조 연산
- + : 새로운 리스트/튜플 추가한다.
- * 숫자 : 숫자만큼 반복해서 새로 생성
- 요소 in 시퀀스 자료 : 요소가 포함되어 있는지 체크 (True, False)

### 명시적 형변환
- list(...) : 다른 컬렉션(튜플, 집합) -> 리스트형으로 변환(새로운 리스트로)
- tuple(...) : 다른 컬렉션(리스트, 집합) -> 튜플형으로 변환(새로운 튜플)

### 딕셔너리 자료구조
- key - Value 쌍 구조
- Key : Value를 찾기 위한 키워드, 중복 x, 리스트는 사용 불가
- Value : key로 찾는 값, 중복 o
- {"키": 값, "키" : 값, ...}

- 추가(Create) : 없는 키이름으로 값을 대입하면 추가
- 조회(Read) : ['키 이름'] - 키가 없으면 key Error 발생
 - get ("키 이름") - 키가 없으면 None 반
 - keys() : 모든 키를 담은 View, 읽기 전용
 - values() : 모든 값을 담은 view,읽기 전용
 - items (): (키, 값) 목록을 담은 View

- 수정(Update) : 이미 있는 키값에 대입하면 수정
  - update({Key, value, Key, value,...})
- 삭제(delete)
  - del items['키']
  - clear(): 전체 비우기
 
  ### 집합 자료구조
- 중복을 허용하지 않는다.
- 순서가 결정되지 않는다.
- {값1, 값2, 값3, ...}

집합연산
- 합집합: a|b -> a와 b의 합집합 (a.union(b))
- 교집합: a&b -> a.intersection(b)
- 차집합: a- b -> a.difference(b)
- 대칭차집합: a ^ b -> a.symmetric_difference(b)
집합 자료로 형변환
- set(리스트 또는 튜플)

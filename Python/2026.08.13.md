## 변수 스코프와 람다 함수
- 변수 스코프(Socpe) : 변수를 접근할 수 있는 범위

### 1. 전역 변수와 지역 변수
- 전역변수 : 함수 외부에 정의된 변수, 코드 전역에서 접근 가능
- 지역변수 : 함수 내부에 정의된 병수, 함수가 실행될때만 유효

### 2. 파이썬의 변수 검색 규칙 : LEGB 스코프
접근 우선 순위: 좁은 범위가 우선순위가 높다.

- L(Local) : 지역 변수
- E(Enclosing) : 외부 함수 변수
- G(Global) : 전역변수
- B(Builtin) - 내장변수

### 3. golbal 키워드

전역함수를 쓰기위한 키워드 

- 무분별에게 남발하면 스코프가 꼬일 수 있음

### 4. 일급 함수
- 함수와 변수를 동일하게 취급
- 함수의 매개변수로 함수를 사용할 수 있다. - 콜백 함수
- 함수의 반환값으로 함수를 사용할 수 있다. - 팩토리 함수, 클로져(Closure)

### 클로져 : 함수가 만들어질 때의 주변 변수(환경)를 기억하고 있는 함수
- 고차 함수(Higher Order Function)

### 5. lambda 함수
- 간단하게 일회용으로 사용하는 경우 한줄의 식으로 간단하게 함수 정의
- 일회용으로 사용되므로 매개변수 이름도 최대한 간결하게(한자)
```python
lambda 매개변수, 매개변수, ...: 처리 부분
```

### 6. lambda와 map(), filter()를 활용한 데이터 일광 가공
- map(): 변화나 작업
- filter(): 특정 조건에서 데이터를  작업

### 데코레이터
- 디자인 패턴 중 하나다.
- a = [10, 20]


### 오늘 배운 점
- 함수를 짧게 쓰는 방법에 대해 배워서 유용한 시간이였다. 클로저라는 개념을 배웠는데 처음에는 어려웠고 이해가 안됬지만 과제를 직접 코드를 만지면서 하다보니 괜찮게 이해가는 느낌이였던 것 같다. 이론은 일단 가르쳐주시는데로 그대로 받아들이고 코드를 작성하면서 개념을 이해하는게 더 도움이 되는 것 같다는 깨달음을 얻었다.

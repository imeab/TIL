## SQL (데이터베이스에 명령어를 내리는 언어)
#### 1. DDL(Data Definition Language) / 데이터 정의어 
- CREATE
    - TRUNCATE TABLE 테이블명(테이블 구조 유지, 초기화)
- ALTER
- DROP
#### 2. DML(Data Manipulation Language) / 데이터 조작어
- INSERT 추가
- UPDATE 수정 
- DELETE 삭제
- SELECT 조회
#### 3. DCL (Data Control Language) / 데이터 제어어
- 권한
    - GRANT : 권한 부여
    - REVOKE : 권한 취소

- 트랜젝션 (TCL)
    - COMMIT : 데이터를 DB에 영구반영
    - ROLLBACK : 지금까지 한 변경 작업을 취소하고 되돌림

#### ex) 서랍장
- DDL: 서랍장 자체 제작 또는 칸수 바꾸거나 통쨰로 부수기
- DML : 서랍장은 그대로 두고 서랍 안의 물건을 넣고 빼고 바꾸는 것
- DCL : 서랍장을 누가 열어볼 수 있는지 정하기
- TCL : 서랍 정리하다가 이대로 확정(COMMIT) 또는 방금 한거 취소 후 원래대로 돌려놔(ROLLBACK)

### 제약조건
#### 기본키 제약조건(PRIMARY KEY)
    - 중복 허용 x
    - 비어있는 값을 허용 X(NULL 불가)
    - 복합키
        - PRIMARY KEY(컬럼명, ... );
- NOT NULL
    - 빈값 X
    - 필수항목(컬럼)
- UNIQUE
    - 중복 허용 X
    - NULL은 중복을 가능
- CHECK 
    - 특정 조건에 해당하는지 체크
- DEFALT 기본값 (직접 지정, 내장 함수 호출, 내장 상수) 
    - 예) 현재날짜와 시간(URRENT_TIMESTAMP)

### 외래키 (Foreign Key)
- 참조 무결성 제약조건이 적용
    - 부모쪽 테이블에 없는 참조값을 자식테이블이 사용 x
    - 부모쪽 레코드에 자식 레코드가 있으면 부모쪽 레코드를 삭제 X
    - ON DELETE
        - CASCADE - 부모 레코드가 삭제가 되면 자식 레코드도 삭제(연쇄 삭제)
        - SET NULL - 부모 "" 자식 레코드의 참조 컬럼의 값을 NULL로 교체


- CREATE TABLE 테이블명 (컬럼명, 자료형, [제약조건 등..] REFERENCES 테이블명(컬럼명))

## 데이터베이스 정규화
데이터 중복과 이상현상을 개선하기 위해서 테이블의 구조를 단계적으로 개선하는 과정

1. 제 1 정규형(1NF) - 원작값 유지
- 하나의 컬럼에는 하나의 값만 있어야한다
- 반복되는 값이나 여러 값을 하나의 컬럼에 넣지 않고, 데이터를 원자값으로 분리한다.

ex) 서랍 한칸에 물건 여러개 뒤섞기 금지

2. 제 2 정규형(2NF)
- 복합키 전체에 종속 되도록 분리

ex) 라벨(기본키) 전체와 관련된 물건만 그 서랍에 두고, 라벨의 절반과만 관련된 물건은 그 절반짜리 라벨을 가진 별도 서랍으로 옮기는 것

3. 제 3 정규형(3NF)
- 일반 컬럼끼리의 의존 관계 제거

ex) 서랍 라벨이랑 직접 관련된 물건만 그 서랍에, 다른 물건을 거쳐서만 연결된 정보는 그 물건 전용 서랍으로

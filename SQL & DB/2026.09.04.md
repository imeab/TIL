## PostgreSQL 따옴표 규칙

- **작은따옴표 `''`**: 문자열 리터럴
- **큰따옴표 `""`**: 구분 식별자 (다음 경우에 사용)
  - 특수문자가 포함된 경우
  - 대소문자를 섞어 쓰는 경우
  - 예약어를 이름으로 써야 하는 경우

## SQL (데이터베이스에 명령어를 내리는 언어)

### 1. DDL (Data Definition Language) — 데이터 정의어

- **CREATE**: 테이블 생성
- **DROP**: 테이블 삭제
- **TRUNCATE TABLE 테이블명**: 테이블 구조는 유지하고 데이터만 초기화
  - 데이터 삭제 시 복구 불가 (ROLLBACK 불가)

### ALTER: 테이블 구조 수정

#### 1) 컬럼 다루기

| 목적 | 문법 |
|---|---|
| 컬럼 추가 | `ALTER TABLE 테이블명 ADD COLUMN 컬럼명 자료형 [제약조건];` |
| 컬럼 이름 변경 | `ALTER TABLE 테이블명 RENAME COLUMN 기존컬럼명 TO 변경컬럼명;` |
| 컬럼 삭제 | `ALTER TABLE 테이블명 DROP COLUMN 컬럼명;` |

#### 2) 컬럼 타입 변경

| 상황 | 문법 |
|---|---|
| 데이터가 없는 경우 | `ALTER TABLE 테이블명 ALTER COLUMN 컬럼명 TYPE 자료형;` |
| 데이터가 있어 형변환이 필요한 경우 | `ALTER TABLE 테이블명 ALTER COLUMN 컬럼명 TYPE 자료형 USING (컬럼명::자료형);` |

#### 3) 컬럼 제약조건 설정/해제 (SET / DROP)

| 목적 | 문법 |
|---|---|
| 제약조건 설정 | `ALTER TABLE 테이블명 ALTER COLUMN 컬럼명 SET 제약조건;` |
| 기본값 설정 | `ALTER TABLE 테이블명 ALTER COLUMN 컬럼명 SET DEFAULT 값;` |
| 제약조건 해제 | `ALTER TABLE 테이블명 ALTER COLUMN 컬럼명 DROP 제약조건;` |

#### 4) 테이블 레벨 제약조건 추가/삭제 (CONSTRAINT)

| 제약조건 종류 | 문법 |
|---|---|
| 기본키 | `ALTER TABLE 테이블명 ADD CONSTRAINT 이름 PRIMARY KEY (컬럼명);` |
| 고유값 | `ALTER TABLE 테이블명 ADD CONSTRAINT 이름 UNIQUE (컬럼명);` |
| 조건 검사 | `ALTER TABLE 테이블명 ADD CONSTRAINT 이름 CHECK (조건식);` |
| 외래키 | `ALTER TABLE 테이블명 ADD CONSTRAINT 이름 FOREIGN KEY (현재컬럼명) REFERENCES 참조테이블(컬럼명) [ON DELETE CASCADE / SET NULL];` |
| 제약조건 삭제 | `ALTER TABLE 테이블명 DROP CONSTRAINT 제약조건이름;` |

**한눈에 정리**

| 카테고리 | 하는 일 |
|---|---|
| 컬럼 다루기 | 추가 / 이름변경 / 삭제 |
| 타입 변경 | 자료형 바꾸기 (데이터 유/무 여부에 따라 USING 사용) |
| SET / DROP | 컬럼 하나에 제약조건 또는 기본값 붙이거나 떼기 |
| CONSTRAINT | 테이블 전체 레벨의 제약조건(PK, UNIQUE, CHECK, FK) 추가/삭제 |

## 테이블 간 관계 유형

### 1:N 관계

한 테이블의 레코드 하나가 다른 테이블의 여러 레코드와 연결되는 관계

> 예) 회원(1) : 주문(N) — 한 명의 회원은 여러 주문을 할 수 있지만, 하나의 주문은 반드시 한 명의 회원에 속함

### N:M 관계 (다대다)

양쪽 테이블의 레코드가 서로 여러 개와 연결될 수 있는 관계

## ERD 기호 읽는 법

| 기호 | 의미 |
|---|---|
| `ㅣ` (수직선 하나) | 최소 1개, 필수 |
| `o` (원) | 0개 (선택적) |
| `<` (까마귀 발) | 여러 개 (N) |
| `ㅣㅣ` (수직선 두 개) | 정확히 1개, 필수 |
| `o<` (원 + 까마귀 발) | 0개 이상 |
| `ㅣ<` (수직선 + 까마귀 발) | 1개 이상 |

## DML (데이터 조작어)

### 1. INSERT — 추가

```sql
INSERT INTO 테이블명 [(컬럼명1, 컬럼명2, ...)]
VALUES (값1, 값2, ...);
```

### 2. UPDATE — 수정

```sql
UPDATE 테이블명
SET 컬럼명1 = 변경할 값,
    컬럼명2 = 변경할 값
[WHERE 조건식(비교연산, 논리연산)];
```

### 3. DELETE — 삭제

```sql
DELETE FROM 테이블명 [WHERE 조건식];
```

## 오늘의 느낀점 / 배운점

- 큰따옴표(`""`)와 작은따옴표(`''`)를 그냥 비슷하게만 알고 있었는데 정리하면서 큰 따옴표와 작은 따옴표의 차이를 알게 되었고 대부분 작은 따옴표를 쓰는 것을 알게 되었다.

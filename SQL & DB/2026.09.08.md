## 서브 쿼리(부속 질의)
#### 1. SELECT 문에 SELECT가 포함된 질의

#### 2. 스칼라 서브쿼리
```sql
SELECT "서브쿼리" FROM
```
#### 3. 인라인 뷰(가상 테이블)
- 실제 물리적 테이블 X 
- 조회 결과를 가지고 테이블처럼 사용가능한 임시테이블
```sql
SELECT ....FROM "서브쿼리"
```
#### 4. 상관 서브 쿼리
- 내부쿼리의 결과룰 외부 쿼리가 사용
```sql
SELECT .. FROM WHERE "서브쿼리"
```

|비교항목|서브쿼리|JOIN|
|---|---|---|
가독성|	조건/계산 로직이 명확하게 분리됨|	여러 테이블 관계를 한눈에 파악 가능|
반환 구조|	외부 쿼리 기준의 열만 선택 가능|여러 테이블의 열을 자유롭게 선택 가능|
성능|	단순 조건 필터링에 유리|대용량 데이터 JOIN에 최적화된 경우 많음|
NULL 처리|	EXISTS 사용 시 안전|OUTER JOIN으로 NULL 제어 가능|
적합한 상황|	집계 결과를 조건으로 사용, 존재 여부 확인|	두 테이블의 열을 함께 조회, 복잡한 관계 표현|

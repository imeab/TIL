# SQL & 데이터베이스

> 날짜: 2026.09.02

## SQL, Data 기초

- 데이터: 처리되지 않은 값(원시값)
- 정보: 데이터에 의미를 부여

### DBMS (DataBase Management System)

데이터를 관리하는 소프트웨어

**1. RDBMS (Relational DBMS)**
- MySQL — 오픈소스 (MariaDB)
- Oracle — 유료
- MSSQL — 유료
- PostgreSQL — 오픈소스

### SQL (Structured Query Language)

- 쿼리(Query): 데이터베이스에 보내는 질문, 질의
- 작성 규칙: SQL

---

## 데이터 저장 모델

### 관계형 (Relational)

- 테이블(Table): 데이터를 저장하기 위한 공간
- 행과 열로 구성된 2차원 구조
  - 행(Row / Record)
  - 열(Column / Field / 속성)
  - 셀: 각각의 데이터 (주문번호, 주문 상품 등)
- 스키마(Schema): 테이블 구조와 제약사항을 정의한 명세서

---

## 데이터 무결성 제약조건

1. **도메인 무결성 제약조건** — 동일 컬럼은 동일한 자료형만 허용
2. **개체 무결성 제약조건 (기본키 제약조건)**
3. **참조 무결성 제약조건**

---

## 자료형 (Data Type)

### 1. 숫자형

**정수**
| 타입 | 크기 |
|---|---|
| SMALLINT | 2byte |
| INT | 4byte |
| BIGINT | 8byte |

**실수**
| 타입 | 크기 | 비고 |
|---|---|---|
| REAL | 4byte | |
| DOUBLE PRECISION | 8byte | |
| DECIMAL(p, s) | - | p: 전체 자리수, s: 소수점 자릿수 |

### 2. 문자형

- `CHAR(자리수)`: 고정 사이즈 문자 (예: 남자, 여자)
- `VARCHAR(최대 자리수)`: 최대 자리수만큼의 문자 (최대를 넘지 않으면 문자 크기만큼만 공간 할당)
- `TEXT`: 여러 줄 텍스트, 길이 제한 없는 가변 문자열

### 3. 논리형

- `BOOLEAN`: TRUE, FALSE, NULL

### 4. 날짜와 시간

| 타입 | 설명 |
|---|---|
| DATE | 날짜 |
| TIME | 시간 |
| TIMESTAMP | 날짜 + 시간 |
| TIMESTAMPTZ | 날짜 + 시간 + 시간대 (기본적으로 UTC 0) |

### 5. JSON

- `JSON`
- `JSONB`: 바이너리로 저장 (속도가 빠름)

### 6. 기타

- `ENUM`: 열거형 — 예) `ENUM('READY', 'ORDER')`
- `VECTOR(차원수)`

---

## 기본키 PK (Primary Key)

- 하나의 레코드를 식별할 수 있는 대표 컬럼 또는 컬럼의 조합
- 중복 불가, 값이 반드시 있어야 함 (NULL 불가)

---

## 오늘의 느낀점 / 배운점

- SQL은 **무결성 제약조건**이 핵심이라는 걸 깨달았다. 데이터가 아무렇게나 쌓이지 않도록 도메인, 개체, 참조 무결성으로 막아주는 구조다
- 자료형을 그냥 외우기보다, **왜 이 타입을 써야 하는지**(예: 돈 계산엔 DECIMAL, 나이엔 SMALLINT)를 이해하니 훨씬 기억에 잘 남았다.

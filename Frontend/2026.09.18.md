### 뷰포트(viewport): 보이는 화면

```html
<meta name="viewport" content="width=device-width,initial-scale=1,minimum-scale=1,maximum-scale=1,user-scalable=no,interactive-widget=resizes-content">
```
 - width
    - device-width :장비의 너비 기준 -> 웹
    - device-height

**user-scalable**
- yes : 확대, 축소 가능
    - minimum-scale: 축소 비율
    - maximun-scale: 확대 비율
    - initial-sclae: 처음화면 비율
- no : 확대, 축소 불가

**모바일**(~ 767px)

**태블릿**(767px ~ 1023px)

**데스크탑**(1024px ~)

**미디어쿼리(@media --)**
- @media 미디어 타입 and (미디어 특성) {
    css 정의
} 
- 미디어 타입
    - screen: 컴퓨터 모니터, 태블릿, 스마트폰
    - print: 프린트에만 해당하는 css
    - speech: 시각장애인용 스크린 리더
    - all(기본값)
- 미디어 특성
 - width/height
 - min-width: ~ 크기 이상
 - max-width: ~ 크기 이하
 - orientation : 기기의 방향
    - portrait: 세로방향
    -landscape: 가로방향

## 1. Flexbox 심화

### flex-grow
- 자식 요소에 적용
- 부모의 남은 공백을 자식들이 나눠 가질 **비율**을 설정

### flex-shrink
- 부모 요소의 공간이 부족할 때, 자식 요소의 크기를 줄이는 비율(가중치)
- `0`으로 설정하면 해당 요소는 축소되지 않음

### flex-basis
- 요소의 기본 사이즈 (기본값: `auto`)

### flex-wrap
- 부모 요소의 너비가 부족하면 다음 줄로 개행
- 기본값은 `nowrap` (개행 안 함)

## 2. CSS Grid (2차원 격자 레이아웃)

### grid-template-columns / grid-template-rows
```css
grid-template-columns: 150px 150px 300px;   /* 컬럼 3개, 각각 사이즈 지정 */
grid-template-columns: 150px 1fr 2fr;       /* fr: 남은 공간에 대한 비율 */
grid-template-columns: repeat(3, 150px);    /* 같은 사이즈 컬럼을 지정 개수만큼 반복 */
```

### gap
```css
row-gap: 20px;      /* 행 간 여백 */
column-gap: 10px;   /* 열 간 여백 */
gap: 20px 10px;      /* row-gap column-gap 단축 표현 */
```

### grid-column / grid-row (아이템이 몇 칸을 차지할지)
```css
grid-column: 1 / 3;   /* 1번 라인 ~ 3번 라인까지 차지 */
grid-column: span 2;  /* 2칸을 차지 */

grid-row: 1 / 3;
grid-row: span 2;
```

### place-items (정렬)
- `stretch` (기본값)
- `start` : 왼쪽 상단
- `end` : 오른쪽 하단
- `center` : 정가운데

## 3. 폰트 & 텍스트

| 속성 | 설명 |
|---|---|
| `color` | 글자 색상 (색상명 / hex / rgb / rgba) |
| `font-size` | 글자 크기 (절대 단위, 상대 단위 `em`, `rem`) |
| `line-height` | 행간. 기본값 `1.2`, 권장 비율은 `1.5` (`%`로도 지정 가능, 예: `150%`) |
| `letter-spacing` | 자간 |
| `word-spacing` | 단어 사이 간격 |
| `word-break` | `normal` / `break-all` 등 줄바꿈 처리 방식 |

### font-weight
- `normal` (기본값, 400)
- `bold` (두껍게, 100~900 범위)
- ⚠️ 지원하는 두께는 폰트마다 다름

### text-align
- 인라인 요소(글)에 대한 정렬
- `left` (기본값) / `right` / `center` / `justify` (양쪽 정렬)

### font-style
- `normal` (기본값)
- `italic` : 기울임체
- `oblique` : 흘림체, 각도 지정 가능 (예: `oblique 90deg;`)

### text-decoration
- `underline` : 밑줄
- `line-through` : 취소선
- `none` (기본값)

### font-family
```css
font-family: 'Malgun Gothic', 'Apple Gothic', sans-serif;
```
- 폰트명에 공백이 있으면 따옴표로 감싸기
- 시스템 폰트: OS에 설치된 폰트
- 웹 폰트: OS 설치 여부와 무관하게 동일하게 공유 가능한 폰트

## 4. overflow (x, y)
- `visible` (기본값) : 넘치는 콘텐츠도 그대로 보임
- `hidden` : 넘치는 콘텐츠를 감춤
- `scroll` : 스크롤바 상시 노출
- `auto` : 콘텐츠가 넘칠 때만 스크롤바 노출

## 5. border (경계선)

```css
border-width: 2px;
border-style: solid;   /* none / solid / dashed / dotted / double */
border-color: red;

/* 단축 표현 */
border: 2px solid red;  /* top, right, bottom, left 모두 적용 */
```

- `border-radius` : 모서리(반지름)를 둥글게

## 6. background (배경)

```css
background-color: #fff;
background-image: url("이미지 경로");
background-repeat: no-repeat;  /* repeat(기본값) / repeat-x / repeat-y / no-repeat */
background-position: 100px 50px;  /* 좌→우 100px, 위→아래 50px 이동 */
background-size: cover;  /* 영역을 꽉 채움(비율 다르면 일부 잘림) / contain: 이미지 전체가 보이도록 */
background-attachment: fixed;  /* fixed: 스크롤해도 배경 고정 / scroll: 배경도 함께 스크롤 */

/* 단축 표현 */
background: 색상 이미지 반복 위치/사이즈 고정;
```

## 7. Positioning (위치)

- `position` 기본값은 `static`

| 값 | 기준점 |
|---|---|
| `relative` | 속성이 정의된 자기 자신의 원래 위치 |
| `absolute` | 문서 전체 기준. 단, 부모 중 `relative`/`absolute`/`fixed`가 있으면 그 부모가 기준점 |
| `fixed` | 뷰포트(viewport) 기준 |

- 층(레이어) 순서는 `z-index`로 설정 → **값이 높을수록 위쪽(앞쪽)에 배치**
- 위치 지정 방향
  - `left` : 좌 → 우로 이동
  - `right` : 우 → 좌로 이동
  - `top` : 위 → 아래로 이동
  - `bottom` : 아래 → 위로 이동

## 오늘 배운 점

- **Flex의 grow/shrink/basis는 한 세트**로 이해하는 게 편하다. grow는 남는 공간을 얼마나 먹을지, shrink는 "부족할 때 얼마나 줄어들지", basis는 "기본 크기"를 정하는 역할 분담이라는 걸 정리하고 나니 헷갈리던 게 풀렸다.

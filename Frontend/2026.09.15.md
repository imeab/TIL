## 1. Form 입력 요소

### input : 입력을 위한 태그

**type**: 입력 유형
- `text` (기본값)
- `password` — 비밀번호
- `radio` — 여러 개 중 하나 선택
- `checkbox` — 여러 개 중 여러 개 선택
- `submit` — 양식 제출
- `reset` — 입력 항목 초기화
- `button` — 일반 버튼
- `email`
- `number`
- `color`
- `range`
- `date`
- `time`
- `datetime`

**name**: 입력 항목의 이름
- 전송할 값의 이름
- `radio`, `checkbox`에서는 같은 그룹을 묶는 명칭으로 사용됨

**value**: 입력값 (`type="text" | "password" | "number"` 등)

**required**: 필수 입력 항목

**placeholder**: 안내 문구

**readonly**: 읽기 전용 (데이터 전송 O)

**disabled**: 기능 무력화 (데이터 전송 X)

### button
- type: `submit` / `reset` / `button`
- `<button>버튼명</button>`

### label과 입력 요소 연결
- 입력 요소를 `<label>` 태그로 감싸거나
- `label`의 `for` 속성과 입력 요소의 `id` 속성을 연결

### textarea
- 여러 줄 텍스트 입력

### select
- 여러 개 중 한 개 또는 여러 개 선택
- `option`: 선택 항목
- `multiple`: 여러 개 선택 가능
- `size`: 한 번에 보일 개수

## 2. 시멘틱 태그
- 의미를 가지고 있는 태그 (예: `form`, `table`, `video`)
- 비시멘틱 태그: `div`, `span`

### 필요한 이유
1. 검색엔진 최적화(SEO)
2. 웹 접근성
3. 코드의 가독성

### 레이아웃을 구성하는 태그
- `header`: 상단 공통 영역
- `footer`: 하단 공통 영역
- `main`: 본문, 하나만 정의
- `section`: 내용 구분
- `article`: 섹션별 내용
- `nav`: 주 메뉴
- `aside`: 왼쪽/오른쪽 영역

## 3. CSS (Cascading Style Sheet)
- 웹 문서의 스타일링 담당

### 기본 구조
선택자 { 속성: 값; 속성: 값; }

### 적용 방법
- 인라인 스타일: 태그의 `style` 속성에 직접 적용
- 내부 스타일 시트: `<style>` 태그 안에 정의
- 외부 스타일 시트: css 파일 생성 후 `<link>`로 연동

### 주석
`/* 설명 */`

### 선택자
- 전체 선택자: `*`
- 태그 선택자: 태그 이름
- 클래스 선택자: `.클래스명` (여러 요소에 중복 지정 가능)
- 아이디 선택자: `#아이디명` (한 문서에서 유일하게 지정)

### 스타일 적용 우선순위
범위가 넓을수록 우선순위 낮음, 좁을수록 높음

`태그 선택자` < `클래스 선택자` < `아이디 선택자` < `style 속성`

(실무에서는 태그 선택자, 클래스 선택자를 가장 많이 사용)

> 참고: `!important`로 우선순위를 강제 적용할 수 있지만 남용 금지

### 복합 관계 선택자
- 하위 선택자 (조상 자손): `조상 자손`
- 자식 선택자 (부모 > 자식): `부모 > 자식`
- 형제 선택자 (형 ~ 동생): `형 ~ 동생`
- 인접 형제 선택자 (형 + 동생): `형 + 동생`

## 오늘의 느낀점


CSS 선택자 우선순위 부분이 오늘 배운 것 중 제일 헷갈렸다. 태그 < 클래스 < 아이디 < 인라인 순으로 우선순위가 올라간다는 건 알겠는데 실제 코드에서 스타일이 안 먹힐 때 이 순서를 바로 떠올리는 연습이 더 필요할 것 같음

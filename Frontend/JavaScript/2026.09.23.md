## 객체 리터럴
- 원시타입 값: 재료가 되는 값 — 숫자, 문자열, 불린
- 객체: 원시타입 외 나머지 전부

### 속성(property)
- **접근**: 마침표(속성명이 변수명 규칙을 따를 때) / 대괄호(그렇지 않을 때)
- **추가**: 새로운 속성명에 값 대입
- **수정**: 기존 속성에 값 대입
- **삭제**: `delete 객체.속성명`

## 함수(function)

```js
function 함수명(매개변수, ...) {
  // 수행할 코드
  return 반환값
}
```

- 함수명 = 함수 객체를 가리키는 이름표(변수와 동일한 개념)

### 함수 실행 평가 과정
- 함수를 실행 가능한 객체(실행 컨텍스트, EC)로 번역하는 과정

## 객체 상속

**프로토타입(prototype) 기반 상속**
- 객체와 객체를 연결하는 방식

**생성자 함수**
- 객체를 생성하는 함수
- 네이밍 관례: 첫 글자 대문자
- `new` 연산자로 호출

**생성자 함수가 객체를 생성하는 과정 (`new`)**
1. 생성자 함수의 `prototype` 객체를 상속
2. 생성자 함수의 `this`를 새로 생성된 객체로 바인딩 후 호출

**prototype 메서드**
- 생성된 객체들이 공유하는 메서드 (인스턴스 메서드)

**생성자.메서드**
- 객체 생성 없이 생성자 자체에서 바로 쓰는 메서드 (정적 메서드)

## 데이터 프로퍼티 vs 접근자 프로퍼티

**데이터 프로퍼티**
- `value`: 값
- `enumerable`: 열거 가능 여부
  - `for...in`, `Object.keys()`에 노출되는지 결정
  - `false`면 노출 안 됨
- `configurable`: 재정의 가능 여부
  - `false`면 삭제도 불가능

**접근자 프로퍼티**
- `get`: 읽기 함수
- `set`: 쓰기 함수
- `enumerable`, `configurable`은 데이터 프로퍼티와 동일한 의미

> 내부 속성 은닉·통제는 접근자로 하고, 진짜 캡슐화는 클로저 등 다른 기법 필요
> (참고) 즉시 실행 함수: 정의와 동시에 바로 호출되는 함수

**`Object.seal()` — 객체 밀봉**
- 속성 추가 ✕ / 삭제 ✕ / 값 변경 ○

**`Object.freeze()` — 객체 동결**
- 속성 추가 ✕ / 삭제 ✕ / 값 변경 ✕

## 직렬화

- 객체를 전송 가능한 문자열 형태로 변환
- JSON 문자열로 변환 시 함수, `undefined`는 변환 불가 → `null` 처리

### JSON 객체
- `JSON.stringify(...)`: JS 객체 → JSON 문자열 (직렬화)
- `JSON.parse(...)`: JSON 문자열 → JS 객체 (역직렬화)

## 인수의 유연성과 가변 매개변수

### arguments 객체
- 함수 호출 시 넘긴 인수 목록이 담기는 유사 배열 객체

```javascript
function sum() {
    let total = 0;
    for (const arg of arguments) {
        total += arg;
    }
    return total;
}

sum(1, 2, 3); // 6
```

### 비구조화 할당
- 구조(배열, 객체)를 분해해서 각각 변수에 할당하는 문법

```javascript
const [a, b] = [1, 2];
const { name, age } = { name: "kim", age: 20 };
```

## 일급 객체로서의 함수
함수는 일급 객체라서 아래 3가지가 가능하다.
- 변수에 할당
- 매개변수로 전달
- 반환값으로 활용

### 화살표 함수
- `function` 키워드 생략
- 매개변수 정의부와 실행 영역(`{}`) 사이에 `=>` 표기
- 코드가 한 줄이면 `{}` 생략 가능, 이때 `return`도 같이 생략해야 함
- 매개변수가 1개면 `()` 생략 가능 (0개, 2개 이상이면 생략 불가)

```javascript
const square = x => x * x;
square(10); // 100
```

### 일반 함수 vs 화살표 함수의 this 바인딩
- 일반 함수: 함수를 호출한 객체가 this
- 화살표 함수: 함수가 정의되는 시점에 this가 이미 결정됨

## 자바스크립트 객체

### 네이티브 객체 (공통 객체)
내장 생성자 객체 표준

- Object
- String: 문자열
- Number: 숫자
    - `NaN`: 숫자가 아닌 값
    - `isNaN(...)`: 숫자가 아닌지 판별
        1. 값을 `Number(...)`로 변환했을 때 `NaN`이 나오면 true, 아니면 false
        2. 숫자 형태의 문자열(`"123"`)은 false로 나옴 (정확한 판별이 어려움)
        3. 정확하게 타입을 확인하려면 `typeof` 사용
    - `parseInt(...)`: 정수로 변환 / `parseFloat(...)`: 실수로 변환
- Boolean: 논리값
    - 원시 래퍼 객체
- Function
- Date
- Error
- RegExp
- Array

### 내장 객체
처음부터 바로 쓸 수 있는 편의 객체

- JSON
    - `JSON.stringify(...)`: 자바스크립트 객체 -> JSON 문자열 (직렬화)
- Math
    - `abs(...)`: 절대값
    - `sqrt(...)`: 제곱근
    - `round(...)`: 반올림
    - `floor(...)`: 내림
    - `ceil(...)`: 올림
    - `trunc(...)`: 소수부 버림
- Symbol: 유일무이한 값을 만드는 객체

### 호스트 객체
런타임 환경에 특화된 객체

- 웹 브라우저 객체
- Node.js 특화 객체

## 배열(Array)
- 원래 배열의 개념: 같은 자료형 + 연속된 공간으로 구성

### 배열 객체 (Array Object)
- 자바스크립트 배열은 모든 타입의 값을 저장할 수 있음
- 여러 개의 데이터를 묶어서 관리 (데이터 군집)

1. `Array` 생성자 함수로 생성
2. `Array.prototype`을 상속받음
3. `instanceof`: 객체의 상속 관계 체크
4. `[...]`(배열 리터럴)은 `new Array(...)`와 동일

### 주요 메서드

**추가**
- `push(...)`: 끝에 요소 추가
- `unshift(...)`: 앞에 요소 추가
- `splice(시작, 삭제 개수, 추가할 요소...)`: 요소를 추가 또는 삭제

**삭제**
- `pop()`: 끝 요소를 꺼냄 (반환 + 제거)
- `shift()`: 앞 요소를 꺼냄 (반환 + 제거)
- `splice(...)`

**수정**
- `map(callback)`: callback에 정의한 내용대로 각 요소를 변환
- `filter(callback)`: callback에 정의한 조건대로 필터링

**조회**
- `forEach(callback)`: 요소를 순회하며 callback 실행
- `indexOf(...)`: 요소의 위치 번호 (왼쪽 -> 오른쪽)
- `lastIndexOf(...)`: 요소의 위치 번호 (오른쪽 -> 왼쪽)
- `Symbol.iterator()`: 반복자, `for...of`의 기반

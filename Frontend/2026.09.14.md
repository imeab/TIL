## 웹 페이지를 이루는 3요소

| 구성 | 역할 | 확장자 |
|---|---|---|
| HTML (HyperText Markup Language) | 뼈대 (구조) | .html, .htm |
| CSS (Cascading Style Sheet) | 스타일링 | .css |
| JavaScript | 동적 요소 | .js |

- **HyperText**: 클릭으로 다른 페이지로 이동할 수 있는 텍스트
- **Cascading**: 상위 요소의 스타일이 하위 요소로 전달(상속)되는 방식
- HTML은 `<태그이름> 내용 </태그이름>` 형태로 구성되며, `<meta>`처럼 내용이 없는 단일 태그는 닫는 태그 없이 사용 가능

## HTML

### 1. 웹 표준
어떤 브라우저를 사용하든 동일한 화면, 동일한 기능을 보장하기 위한 규칙

### 2. 기본 구성
`<!DOCTYPE html>`은 HTML 버전을 명시하는 선언문

```html
<!DOCTYPE html>
<html> <!-- 문서 시작 -->
  <head>
    <!-- 문서 정보(title, meta), CSS/JS 등 외부 자원 연결 -->
  </head>
  <body>
    <!-- 실제 화면에 출력되는 부분 -->
  </body>
</html> <!-- 문서 종료 -->
```

### 3. 태그 (문서와 관련성이 높음)

**제목 태그 (Heading)**
```html
<h1> 주제목 </h1>
<h2> 하위제목 </h2>
```
`<h1>` ~ `<h6>`까지 있으며 숫자가 클수록 하위 제목

**본문 서식 태그**
```html
<p> ~ </p>       문단
<b> ~ </b>       두껍게
<strong> ~ </strong>  두껍게 (의미상 강조)
<i> ~ </i>       기울임체
<u> ~ </u>       밑줄
<del> ~ </del>   취소선
<strike> ~ </strike>  취소선
<br>             줄바꿈
```

### 4. 주석
- 코드에 대한 설명을 남기거나, 특정 코드의 출력을 잠시 배제할 때 사용
- 형식: `<!-- 설명 / 출력을 배제할 코드 -->`

### 5. 문단 태그 (Block 요소)
- 줄바꿈이 일어남
- `p`, `div`, `h1~h6`, `form` 등
- 자체적으로 공간(너비, 높이)을 가지며 설정 가능

### 6. 글 태그 (Inline 요소)
- 줄바꿈이 일어나지 않음
- `i`, `b`, `strong`, `u`, `a`, `span` 등
- 별도의 공간을 가지지 않아 너비/높이를 직접 결정할 수 없음

### 하이퍼링크

#### 1. `<a>` : 하이퍼링크 태그
태그에 추가 정보를 주는 것을 속성(attribute)이라 함

- **href**: 이동할 경로
  - 절대경로
    - 전체 URL
    - 전체 파일 경로 (경로가 바뀌면 출력 안 됨)
  - 상대경로
    - `./` : 현재 파일이 있는 폴더 경로 (현재 경로)
    - `../` : 현재 폴더의 상위 폴더

- **target**: 링크를 출력할 창의 위치
  - `_self` (기본값) — 현재 창
  - `_blank` — 새 창
  - `parent` — 바로 위 부모 창
    - `<iframe>` : 자식 창
      - `src` : 창에 출력할 경로
      - `name` : 창의 이름 설정
  - `top` — 가장 상위 창
  - 지정한 창 이름

#### 2. 양식(Form) 태그
- **action**: 제출 처리할 URL

**input : 입력을 위한 태그**
- **type**: 입력 유형
  - `text` (기본값)
  - `password` — 비밀번호
  - `radio` — 여러 개 중 하나 선택
  - `checkbox` — 여러 개 중 여러 개 선택
  - `submit` — 양식 제출
  - `reset` — 입력 항목 초기화
  - `button` — 일반 버튼
- **name**: 입력 항목의 이름
  - `radio`, `checkbox`에서는 같은 그룹을 묶는 명칭으로 사용됨

## 오늘 배운 점
- HTML은 단순히 "태그 외우기"가 아니라 **문서의 구조를 표현하는 언어**라는 걸 다시 이해했다. `head`는 문서 정보, `body`는 실제 출력이라는 역할 구분이 명확해졌다.
- `href`의 절대경로, 상대경로 개념이 실무에서 왜 중요한지 감이 왔다. 절대경로는 파일 위치가 바뀌면 깨질 수 있어서, 프로젝트 내부 링크는 상대경로를 쓰는 게 안전하다는 점을 기억해야겠다.

# 원격 저장소(GitHub)
>날짜: 2026.08.05

----

## 원격 저장소(Remote Repository)

원격 저장소는 GitHub처럼 인터넷에 있는 저장소를 말한다.

로컬 저장소에서 작업한 내용을 원격 저장소에 올리거나,
원격 저장소의 변경 사항을 내 컴퓨터로 가져올 수 있다.

---

# 원격 저장소 연결

GitHub에서 Repository를 만든 뒤 로컬 저장소와 연결한다.

```bash
git remote add origin https://github.com/사용자명/저장소.git
```

### 연결 확인

```bash
git remote -v
```

실행 결과

```bash
PS C:\git\project> git remote -v

origin  https://github.com/user/git-study.git (fetch)
origin  https://github.com/user/git-study.git (push)
```

`origin`은 원격 저장소의 별칭이다.

---

# Push

로컬 저장소의 커밋을 GitHub로 업로드한다.

```bash
git push origin main
```

처음 Push하는 경우

```bash
git push -u origin main
```

`-u` 옵션을 사용하면 이후부터는 `git push`만 입력해도 된다.

### 실행 화면

```bash
PS C:\git\project> git push origin main

Enumerating objects: 8, done.
Counting objects: 100% (8/8), done.
Writing objects: 100% (8/8), done.
To https://github.com/user/git-study.git
 * [new branch]      main -> main
```

---

# Clone

GitHub 저장소를 내 컴퓨터로 복사할 때 사용한다.

```bash
git clone https://github.com/user/git-study.git
```


---

# Fetch

원격 저장소의 변경 사항만 가져온다.

병합(Merge)은 하지 않는다.

```bash
git fetch origin
```

가져온 내용을 확인한 뒤 직접 Merge할 수 있어서 안전하다.

---

# Pull

원격 저장소의 최신 내용을 가져와 자동으로 병합한다.

```bash
git pull origin main
```

---

## Fetch와 Pull 차이

| Fetch | Pull |
|--------|------|
| 변경 사항만 가져온다. | 가져오면서 자동으로 병합한다. |
| 직접 확인 후 Merge 가능 | 바로 Merge가 진행된다. |

---

# Pull Request(PR)

Pull Request(PR)는

**"내가 작업한 브랜치를 main 브랜치에 합쳐 주세요."**

라고 요청하는 기능이다.

팀 프로젝트에서 가장 많이 사용한다.

### 진행 순서

1. 브랜치 생성

```bash
git switch -c feature/login
```

2. 기능 개발

3. Commit

```bash
git add .
git commit -m "feat: 로그인 기능 추가"
```

4. GitHub에 Push

```bash
git push origin feature/login
```

5. GitHub에서 **Compare & Pull Request** 버튼 클릭

6. 변경 내용을 확인하고 PR 생성

7. 팀원이 코드 리뷰 후 Merge

---

# PR을 사용하는 이유

- 바로 main 브랜치에 반영하지 않는다.
- 다른 팀원이 코드를 리뷰할 수 있다.
- 문제가 없는지 확인 후 병합할 수 있다.
- 협업 시 실수를 줄일 수 있다.

---

# PR Merge

코드 리뷰가 끝나면 GitHub에서 Merge 버튼을 눌러 병합한다.

병합이 완료되면 로컬 저장소도 최신 상태로 만든다.

```bash
git pull origin main
```

---

# 팀 프로젝트 작업 순서

```text
main 최신 내용 받기
        ↓
브랜치 생성
        ↓
기능 개발
        ↓
git add
        ↓
git commit
        ↓
git push
        ↓
Pull Request 생성
        ↓
코드 리뷰
        ↓
Merge
        ↓
git pull
```

---

# 자주 사용하는 원격 저장소 명령어

```bash
git remote -v        # 연결 확인
git push             # 원격 저장소 업로드
git pull             # 최신 내용 가져오기
git fetch            # 변경 사항만 가져오기
git clone            # 저장소 복제
```

---

# 오늘 배운 점

- 로컬 저장소와 GitHub는 `git remote add`로 연결한다.
- `git push`는 로컬의 커밋을 원격 저장소에 업로드한다.
- `git pull`은 원격 저장소의 변경 사항을 가져오면서 병합까지 진행한다.
- `git fetch`는 변경 사항만 가져오기 때문에 내용을 확인한 뒤 병합할 수 있다.
- 팀 프로젝트에서는 기능별로 브랜치를 만들어 작업한 후 Pull Request를 통해 코드 리뷰를 받고 Merge하는 방식으로 협업한다.
